## ⚡ Quick Formula to Call Any Plugin / Skill

When chatting with the AI agent, you can prompt in any of these formats:

### Format A: Explicit Direct Trigger (Recommended)
> *"Please use the `[skill-name]` skill to [describe your specific task]."*

### Format B: Outcome-Driven Trigger
> *"I want to [action]. Make sure to apply guidelines from the `[plugin-name]` plugin."*

### Format C: Combined Multi-Skill Feature
> *"Implement [feature] using `full-stack-orchestration-full-stack-feature`, ensuring Firestore listeners follow `firestore-realtime-engine` and UI strictly adheres to `ui-ux-anti-slop`."*
