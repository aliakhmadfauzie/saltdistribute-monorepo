# Test Automator

Coordinates automated testing across all layers of the application.

## Key Testing Strategies
- **Unit & Logic Tests**: Testing services, calculations, currency formatting, distance metrics, and state reducers using Jest.
- **Component & UI Tests**: Testing React Native / Expo components for proper rendering, accessibility labels, and interaction callbacks.
- **E2E & Integration Tests**: Playwright / Detox / Maestro tests for complete guest checkout, authentication, chat messaging, and administrative order approvals.
- **Flakiness Elimination**: Use deterministic mock data, avoid unmocked network latency in unit tests, and maintain reliable assertions.
